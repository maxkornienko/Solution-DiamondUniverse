# Архитектурное видение

## Задача

Помочь «Diamond Universe» дать покупателям возможность оценить алмазы и участвовать в торгах на аукционе, не приезжая в офис.

## Контекст

После глобального шока в 2020 году, который обрушил глобальные продажи ювелирных изделий с бриллиантами примерно на 15%, необработанных алмазов примерно на треть, а поставки алмазов на огранку — почти наполовину, рынок драгоценных камней изменился в сторону онлайн-продаж. Благодаря этому глобальные продажи ювелирных изделий начали восстанавливаться. Компания «Diamond Universe» приняла решение перейти в онлайн для восстановления своих показателей.

### Текущее состояние

В текущем решении ИС «Аукцион» автоматизирует только проведение аукционов офлайн в офисе. Для планирования работ, присвоения идентификаторов и подготовки ведомостей занимается ИС «Алмазы».

ИС «Логистика» занималась перевозкой алмазов по стране и за границу.

ИС «Бухгалтерия» оплачивала услуги компаний-перевозчиков и занимается ведением контрактов.

### Ограничения

Необходимо оплачивать услуги лаборатории и организовывать транспортировку алмазов до лаборатории и обратно, сейчас эксперты могут только лично провести анализ в офисе.
Аукцион проводится офлайн в офисе, поэтому личное присутствие экспертов обязательно.
Идентификация алмазов в связи с отсутсвие интеграции не проводится между ИС "Алмазы" и ИС "Аукцион".

### Целевое состояние

ИС «Алмазы» присваивает идентификаторы, планирование работ по проведению аукциона, логистики до лаборатории и обратно, а также до покупателей. Готовит ведомости и отбирает алмазы для цифрового аукциона.

ИС «Аукцион» ведет описание алмазов для цифрового аукциона, публикует данные для клиентов и проводит цифровой аукцион.

ИС «Лаборатория» проводит анализ алмазов, готовит и передает описания.

ИС «Логистика» перевозка алмазов, в т.ч. в лабораторию и покупателям.

ИС «Бухгалтерия» актирование и оплата услуг лаборатории, компаний-перевозчиков, ведение контрактов.

## Описание оптимального решения

### Возникающие вызовы

Не учтены заключение контракта с лабораторией, согласования их нагрузки, подготовки результатов анализа, чтобы быть готовым к изменению процессов; требуется заняться в первую очередь.
Оцифровка в лаборатории требует перестройки процесса планирования работ и дополнительной доработки интеграции с ИС «Алмазы» — ИС «Логистика» для возврата алмазов в офис.
Оцифровку для ИС "Аукцион" можно будет получить либо по почте в зашифрованном архиве, либо через перевозчика вместе с алмазами.
Для уведомления об аукционе сообщить экспертам по почте/телефону/мессенджер. ИС «Аукцион» будет публиковать в формате Excel по утвержденному шаблону оцифровку и характеристики слота.

### Основные этапы и сроки

1. Первый онлайн-аукцион через 2 месяца.
2. Целевое решение через год.

### Для реализации потребуется

Команда разработки включающая аналитиков, разработчиков бэкенд и фронтенд, QA, SRE, дизайнера — для автоматизации интеграции и автоматизации всех шагов процесса существующих ИС.
Сотрудник ИБ — для обеспечения безопасности выделенных каналов и сервисов.

DNS и сертификаты TLS — базовая инфраструктура сайта.
Потребуется инфраструктура для разворачивания сервисов на собственном сервере.
Описание реализации ИС «Лаборатория» - для интеграции с системами компании.
Cloud.ru - для публикации данных для клиентов
